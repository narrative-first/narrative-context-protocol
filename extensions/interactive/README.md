# `ncp-interactive:` Extension

Status: namespace placeholder for NCP 3.0.0-rc.1 review.

Interactive narrative, game state, branching, player choice, simulation, and engine-specific information belongs in a separately versioned extension rather than in NCP Core or the Dramatica Storyform Profile.

This candidate reserves `ncp-interactive:` as an example extension namespace. It does not yet define a schema or conformance requirements. A future proposal must identify its data model, ownership, compatibility rules, migration path, and relationship to Core references.
