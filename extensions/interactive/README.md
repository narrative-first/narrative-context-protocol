# `ncp-interactive:` Extension

Status: reserved namespace without a published schema or conformance requirements.

Interactive narrative, game state, branching, player choice, simulation, and engine-specific information belongs in a separately versioned extension rather than in NCP Core or the Dramatica Storyform Profile.

NCP 3.0.0-rc.1 reserves `ncp-interactive:` as an example extension namespace. An implementation must not claim conformance to an `ncp-interactive:` schema until a separately versioned schema and conformance policy are published. A proposal should identify its data model, maintainer, compatibility rules, migration path, and relationship to Core references.
