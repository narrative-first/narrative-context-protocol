# Frozen Legacy Combined Schema

`ncp-schema.json` and `ncp-schema.yaml` are the previously published combined schema retained for backward compatibility and release-history preservation. They continue to support existing consumers.

This legacy surface is frozen against new Dramatica relationships, algorithms, structural rules, model logic, diagnostics, semantic mappings, and alternative-framework additions. It is not the NCP 3 layered architecture.

New narrative-neutral work belongs in [`../core/`](../core/). Dramatica transport guidance belongs in [`../profiles/dramatica/`](../profiles/dramatica/). Passing the legacy schema does not prove that a Storyform is complete, coherent, or semantically valid.
