# NCP JSON Serialization

JSON is the first machine-readable serialization of NCP. JSON is only the serialization: it is not the Narrative Context Protocol, a Dramatica Storyform, or the Dramatica Semantic Model.

The normative Core JSON Schema is [`../../core/ncp-core-schema.json`](../../core/ncp-core-schema.json). Profile and extension schemas are versioned separately. A future serialization may represent the same protocol model without changing Core semantics.
