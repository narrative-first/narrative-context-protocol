# OMC Binding Examples

The candidate binding examples live in [`../../bindings/omc/examples/`](../../bindings/omc/examples/). They illustrate embedded and externally referenced NCP Custom Data Blocks without copying OMC's production model or redefining any profile semantics.

These fragments are checked by the local NCP test suite. They are not complete OMC documents and must not be presented as OMC schema-validation fixtures.
